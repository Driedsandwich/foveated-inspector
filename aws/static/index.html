How it works

The overview supplies a belief for each cell. The agent spends its fine inspection budget where evidence is strongest, zooms into ambiguity, and follows lines across cell borders.

Low-resolution evidence stays an unconfirmed candidate. A confirmed model report requires full-resolution evidence. Review queued cells before making an inspection decision. This demo does not certify structural safety.
